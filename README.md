# Age Calculator

A responsive and interactive age calculator built using HTML, CSS, and JavaScript.

This project calculates a user's exact age based on their date of birth and provides additional information such as total months, total days, and the number of days remaining until their next birthday.

## ✨ Features

* Calculate exact age in years, months, and days
* Calculate total months lived
* Calculate total days lived
* Next birthday countdown
* Birthday celebration message
* Date validation
* Prevent future date selection
* Reset functionality
* Dark mode
* Light / dark theme persistence using localStorage
* Smooth animations
* Responsive design
* Mobile-friendly interface
* Keyboard-friendly navigation
* Visible focus states
* Accessibility-friendly labels
* Reduced-motion support
* Leap-year date support
